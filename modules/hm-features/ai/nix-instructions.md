## Nix / NixOS: verify before editing

- For every Nix task, inspect `flake.nix`, `flake.lock`, existing modules, and project instructions first. Use the `nixos` MCP (`mcp-nixos`) before recommending or changing package attributes, modules, options, or library functions. Discover tools if hidden; don't guess names and rely on evaluation to catch mistakes.
- Query available channels and use the matching NixOS release, not unstable or moving stable as a silent substitute for the pin. Use `nix` to search, then look up the exact attribute or option in the right source (`nixos`, `home-manager`, `darwin`, `nixvim`, `noogle`). Check option types, defaults, examples, and required imports; distinguish NixOS from Home Manager.
- Online results aid discovery but don't prove availability at the pin. In the project directory, use `nix(action="flake-inputs", type="list")` and `ls`/`read` to inspect pinned sources, especially release differences, third-party modules, and flake-parts options. If MCP runs elsewhere, resolve locked input store paths with local Nix and read them directly. Verify module exports and explicit import/activation paths, not just option names.
- If MCP is unavailable or a lookup fails, say so. Check pinned local sources or official docs, identify what's unverified, and never present guesses as confirmed. Don't install an unpinned replacement server.
- Prefer declarative Nix and existing module options over imperative scripts. Keep expressions simple; factor bindings only for clarity or less repetition. Pin external inputs in the flake lock file; no impure fetches.
- Format with `nix fmt` (fallback: `nixfmt`). Lookups and source checks don't replace evaluation or builds. After source verification and formatting, ask the user to evaluate the affected flake/config when practical. Report which checks ran; claim evaluation or build success only with evidence.
- For multiple dependencies, first try one Nix shell with all of them. If the need isn't one-off or requires NixOS config changes, recommend updating the NixOS configuration, then try another method.
